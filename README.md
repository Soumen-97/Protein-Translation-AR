# 🧬 Protein Translation AR Lab

An interactive **Augmented Reality (AR)-based educational tool** to visualize and understand **protein translation** in real time using hand tracking.

Developed as part of PhD research at **CSIR-IGIB**, this tool transforms abstract molecular biology concepts into an immersive learning experience for students (Class 9–12 and beyond).

---

## 🌐 Live Demo

👉 https://Soumen-97.github.io/protein-translation-ar-lab/

*(Open on Chrome/Edge and allow camera access)*

---

## 🎯 Key Features

* ✍️ **Draw mRNA Strand** using hand gestures
* 🤏 **Grab & Position Ribosome** with pinch interaction
* 🔬 **Simulate Translation (5' → 3')** in real-time
* 🧬 **Codon → Amino Acid Mapping** with visual feedback
* 🔊 **Audio Feedback System** for nucleotides and translation events
* 🎉 **Polypeptide Chain Formation + Completion Animation**
* 📊 **Progress Tracking + Summary Panel**

---

## 🧠 Learning Outcomes

This tool helps users:

* Understand **central dogma (DNA → RNA → Protein)**
* Visualize **codon-based translation**
* Learn **start/stop codons (AUG, UAA)**
* Explore **ribosome dynamics and polypeptide synthesis**
* Build intuition for **molecular processes in 3D space**
